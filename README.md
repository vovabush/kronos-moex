# Kronos на акциях Московской биржи

Тестовый скрипт: дневные свечи акции TQBR, локальный прогноз моделью [Kronos-base](https://github.com/shiyu-coder/Kronos).

Модель видит 400 торговых дней и не видит последние 90. Прогноз на 120 дней: первые 90 рисуются поверх факта, последние 30 уходят дальше последней известной свечи. Синяя линия — факт, красная — прогноз.

Это проверка модели, не торговая стратегия. Прогноз не привязан к вчерашнему закрытию: первая красная точка может заметно отходить от последней синей, если цена далеко ушла от средней за 400 дней.

## Что нужно для запуска

- Python 3.10 или новее. Проверено на Python 3.13 в Windows.
- Интернет при первом запуске: свечи берутся с [MOEX ISS](https://iss.moex.com), календарь рабочих дней — с [isdayoff.ru](https://isdayoff.ru), веса модели — с Hugging Face.
- Видеокарта NVIDIA не обязательна. На RTX 4070 один прогноз занимает около двух секунд. На процессоре тот же расчёт идёт дольше.

Веса в репозиторий не входят. При первом запуске скачиваются `NeoQuasar/Kronos-base` (около 409 МБ) и `NeoQuasar/Kronos-Tokenizer-base` (около 16 МБ).

## Установка

Из этой папки:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python -m pip install -r requirements.txt
```

Команда с `cu128` ставит PyTorch для видеокарт NVIDIA. Если карты нет, вместо неё:

```powershell
.\.venv\Scripts\python -m pip install torch
```

## Запуск

```powershell
.\.venv\Scripts\python predict_moex.py SBER
.\.venv\Scripts\python predict_moex.py GAZP
```

Аргумент — тикер акции основного режима TQBR, например `SBER`, `TATN`, `GAZP`, `ROSN`. Фьючерсы, индексы и другие режимы скрипт не принимает.

Откроется окно с двумя панелями: цена закрытия и объём. Та же картинка сохраняется в `outputs/<ТИКЕР>_kronos_base.png`. Закройте окно, чтобы скрипт завершился.

В консоли печатаются даты контекста, скрытого участка и прогноза без факта, а также MAE и MAPE закрытия на 90 скрытых днях.

## Откуда данные

Дневные свечи:

`https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/<ТИКЕР>/candles.json`

Колонка `value` Московской биржи передаётся модели как оборот (`amount`). Сегодняшняя незакрытая свеча отбрасывается.

Будущие 30 дат — это рабочие дни производственного календаря РФ после последней известной свечи. 31 декабря пропускается: в этот день обычной сессии акций нет.

## Модель

Kronos — открытая модель для финансовых свечей (Университет Цинхуа, AAAI 2026). Статья: [arXiv:2508.02739](https://arxiv.org/abs/2508.02739). Здесь используется вариант Kronos-base, 102 миллиона параметров, контекст до 512 свечей. Счёт идёт локально, на GPU, если CUDA доступна, иначе на CPU.

Код в `Kronos/` взят из репозитория Shi Yu и распространяется по лицензии MIT. Веса публикует организация NeoQuasar на Hugging Face.
